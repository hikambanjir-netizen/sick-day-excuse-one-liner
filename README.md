One line under 200 characters that gets you out of work and gets a laugh: the funniest sick-day excuse that lands in one breath. A doctor's note, a pulled muscle, and the snooze button — half believable, fresh, and the twist arrives right at the end.

## Run it

```sh
python3 main.py
```

This writes the single excuse line to `/output/entry.txt` (override with `MAKEFUN_OUTPUT_DIR`).
